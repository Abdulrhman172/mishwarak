02 · Architecture

معمارية التطبيق

نتبع نمط Clean Architecture مع Feature-first structure

🎨
1. Presentation Layer — الواجهة
Screens · Widgets · Themes — كل شيء يراه المستخدم
↓
⚡
2. State Layer — إدارة الحالة
Riverpod Providers · State Notifiers — منطق الشاشات
↓
🧠
3. Domain Layer — منطق الأعمال
Models · Use Cases · Repositories interfaces — قواعد التطبيق
↓
💾
4. Data Layer — البيانات
API Services · Local Storage · Firebase — مصادر البيانات
💡 لماذا هذه المعمارية؟

فصل واضح للمسؤوليات، سهولة اختبار كل طبقة على حدة، سهولة استبدال أي طبقة (مثلاً تغيير Firebase إلى backend مخصص)، وإمكانية توسيع الفريق بأمان.

03 · Quick Start

البدء السريع

خطوات إعداد المشروع في أقل من 10 دقائق

1

ثبّت Flutter SDK

تحقق من الإصدار: flutter --version — يجب أن يكون 3.19+

2

أنشئ مشروع جديد

# إنشاء مشروع Flutter مع دعم iOS + Android
flutter create --org com.mishwarak --project-name mishwarak mishwarak
cd mishwarak
3

انسخ ملف pubspec.yaml من هذا الدليل

يحتوي على كل الحزم المطلوبة، ثم شغّل:

flutter pub get
4

أنشئ مشروع Firebase

من Firebase Console → أضف iOS + Android app → نزّل google-services.json و GoogleService-Info.plist 

# استخدام FlutterFire CLI للإعداد التلقائي
dart pub global activate flutterfire_cli
flutterfire configure
5

احصل على مفتاح Google Maps

من Google Cloud Console → فعّل Maps SDK for Android + iOS → أنشئ API Key

6

شغّل التطبيق!

flutter run

مثال Riverpod Provider مع حفظ في SharedPreferences:

lib/core/providers/theme_provider.dart dart 
final themeModeProvider =
    StateNotifierProvider<ThemeModeNotifier, ThemeMode>((ref) {
  return ThemeModeNotifier();
});

class ThemeModeNotifier extends StateNotifier<ThemeMode> {
  ThemeModeNotifier() : super(ThemeMode.system) {
    _load();
  }

  static const _key = 'theme_mode';

  Future<void> _load() async {
    final prefs = await SharedPreferences.getInstance();
    final index = prefs.getInt(_key) ?? ThemeMode.system.index;
    state = ThemeMode.values[index];
  }

  Future<void> setMode(ThemeMode mode) async {
    state = mode;
    final prefs = await SharedPreferences.getInstance();
    await prefs.setInt(_key, mode.index);
  }
}

// الاستخدام في أي Widget:
class SettingsScreen extends ConsumerWidget {
  @override
  Widget build(context, ref) {
    final mode = ref.watch(themeModeProvider);
    return Switch(
      value: mode == ThemeMode.dark,
      onChanged: (v) => ref.read(themeModeProvider.notifier)
          .setMode(v ? ThemeMode.dark : ThemeMode.light),
    );
  }
}

09 · Launch Checklist

قائمة قبل النشر

تأكد من كل هذه العناصر قبل النشر على المتاجر

🔒 الأمان

  • تخزين tokens في flutter_secure_storage
  • Obfuscation للكود (--obfuscate --split-debug-info)
  • SSL Certificate Pinning
  • حماية من الـ Root/Jailbreak detection
  • عدم طباعة أي بيانات حساسة في logs

⚡ الأداء

  • const constructors أينما أمكن
  • ListView.builder بدلاً من ListView
  • Cache للصور (cached_network_image)
  • تجنب rebuilds غير ضرورية
  • اختبار على أجهزة بطيئة (Android Go)

🌍 التوطين

  • كل النصوص في ملفات .arb
  • اختبار RTL كامل
  • تنسيق الأرقام والتواريخ (intl)
  • عملة العملة (ر.ي)
  • خطوط عربية مضمّنة

📊 التحليلات

  • Firebase Analytics للأحداث
  • Crashlytics لمتابعة الأخطاء
  • Performance Monitoring
  • User Properties (نوع المستخدم، المنطقة)

♿ الوصولية (Accessibility)

  • Semantics labels على الأزرار
  • حجم نص قابل للتكبير
  • تباين ألوان كافي (WCAG AA)
  • مناطق النقر ≥ 44px

📱 متطلبات المتاجر

  • أيقونات بكل المقاسات المطلوبة
  • لقطات شاشة (iPhone + iPad + Android)
  • Privacy Policy + Terms of Service
  • وصف التطبيق (ar + en)
  • App Store Connect / Play Console
⚠️ تنبيه مهم للسوق اليمني

لا يوجد Google Pay أو Apple Pay في اليمن. ركّز على: الدفع النقدي، محافظ الاتصالات (فلوسي)، البطاقات المحلية. قد تحتاج للتكامل مع بنك محلي مثل بنك التسليف التعاوني أو الكريمي.
