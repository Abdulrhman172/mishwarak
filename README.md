# Mishwarak (مشوارك)

A ride-hailing app design and prototype project.

## Contents

- **`Mishwarak.html`** — Interactive React/JSX design prototype (design system, screens, and component tweaks) rendered directly in the browser via Babel standalone.
- **`design-system.js`**, **`design_canvas.jsx`**, **`tweaks_panel.jsx`** — Shared design tokens and the live-editing canvas for the prototype.
- **`icons.jsx`**, **`avatars.jsx`**, **`map-component.jsx`**, **`android_frame.jsx`**, **`ios_frame.jsx`** — Reusable UI components used across the prototype screens.
- **`screens-*.jsx`** — Individual app screens (onboarding, home, ride, menu).
- **`flutter_code/`** — The Flutter implementation of the app.
- **`screenshots/`** — Reference screenshots of the prototype at various stages.
- **`Flutter Developer Guide.html`** — Guide for developers working on the Flutter implementation.

## Getting Started

To view the design prototype, open `Mishwarak.html` in a browser.

To run the Flutter app, see [flutter_code/README.md](flutter_code/README.md).
